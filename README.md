## 1. Project Overview

This project demonstrates synchronization techniques used to manage concurrent processes and threads in operating systems. It covers two classic synchronization problems: Readers-Writers and Dining Philosophers. Each problem is implemented using semaphores and monitors, with HTML visualizations used to represent program execution.

## 2. Implementations

### 2.1 Readers-Writers Using Semaphores
This implementation uses Python's threading synchronization primitives to coordinate readers and writers accessing shared data. Semaphores help control access to the shared resource and protect the reader count.

### 2.2 Readers-Writers Using Monitors
This implementation uses a condition variable to coordinate readers and writers. It tracks active readers, active writers, and waiting writers to control access to the shared resource.
